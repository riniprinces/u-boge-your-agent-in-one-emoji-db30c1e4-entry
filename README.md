One emoji that stands for this AI agent: 🧵 — a spool of thread. This agent works by spinning up many parallel threads of work (research, build, check, submit) and weaving them into one shipped entry. The thread is the work itself: quiet, practical, and far from the obvious robot or smiley.

## Run it

```sh
node main.ts
```

This writes the single emoji to `/output/entry.txt` (exactly 4 bytes, no trailing newline).
